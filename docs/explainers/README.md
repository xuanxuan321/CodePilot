# docs/explainers

面向零基础读者的可视化科普页面。每篇都是**单文件、零依赖**的 HTML，双击即可用浏览器打开，也可以直接嵌入文章或分享给用户。

| 文件 | 讲什么 | 适合谁看 |
| --- | --- | --- |
| [what-is-an-agent.html](./what-is-an-agent.html) | 用一张大图解释 Agent 是什么：想 → 做 → 看的循环，以及它和普通 AI 聊天的区别 | 完全不了解 AI Agent 的新用户 |

## 写作约定

- 一图为主、文字为辅：核心概念必须能靠一张图讲完，正文只做点睛
- 插图用内联 SVG，不引用外部图片、字体、CDN，保证离线可用
- 同一张图提供横排（宽屏）和竖排（窄屏）两个版本，避免手机上缩成看不清的小图
- 语言口语化，用生活化类比代替术语
